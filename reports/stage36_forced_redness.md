- **Cutoff:** Ghana eyelids (CP-AnemiC, 388 photos), nails and palms (302 linked children): children 6-59 months, **Hb < 11.0 g/dL** on every set. Ghana only (India and Italy are kept for audits; not used here).
- **Inputs:** only color numbers (no hospital, file name, child ID or photo size). Gradient boosting, free and with P(anemic) only allowed to fall as a redness number rises, on each input set; dummy and the untrained rule (minus mean a*) next to them. 5-fold CV x 5 repeats by photo / child, scores averaged over repeats; the eyelids also leave one hospital out. Bootstrap 95% CIs, 2000 resamples.
- **Checks:** Stage 30's jump test (within 1.0 g/dL, 2000 steady draws, jumps if p < 0.025); Stage 33's step at the cutoff (within 2.0 g/dL, score SDs); Stage 32's seven test-photo edits (brightness x0.85, brightness x1.15, gamma 0.8, gamma 1.25, saturation 0.8, white balance R x1.08, B x0.92, white balance R x0.92, B x1.08), an edit breaks a model if AUROC drops >= 0.05 (CI below 0) while the rule moves < 0.02.
- **No trace we can find** = jump p >= 0.025, step CI includes 0, no edit breaks it (rule: the first two). Not proof: the jump test caught 10 of 24 planted traces in Stage 33.
