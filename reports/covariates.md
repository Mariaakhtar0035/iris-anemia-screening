# Stage 31: do village covariates (malaria, bed nets, rainfall, travel time, night lights) add anything?

Generated by `python -m src.survey.covariates` at commit `5a166ad + uncommitted changes`; settings in `configs/covariates.yaml`, written before running (Zimbabwe first, Malawi and Zambia added later, same design).

- **Data:** the DHS Geospatial Covariates file of each country, joined on village number. Values are averages over a 2 km (town) or 10 km (rural) circle around the village's displaced GPS point. Building women only (the Stage 29 locked tests are spent and not touched).
- **Targets:** any anemia (adjusted Hb < 12.0 g/dL, or < 11.0 if pregnant) and moderate or severe (adjusted Hb < 10.0 g/dL for every woman).
- **Evaluation:** village split, 5 x 5 cross-validation (the Stage 30 folds); the first six models of each country are Stage 30's saved predictions. Village-bootstrap 95% CIs, 2000 resamples. Blank covariates are left blank; the models handle them.
