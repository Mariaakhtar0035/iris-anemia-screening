# Stage 24: one Ghanaian child's eyelid, nail and palm photos together

Generated by `python -m src.ghana_link` at commit `c873338`; settings in `configs/ghana_link.yaml`. Mentor suggestion (2026-11-03): put each child's nail and eyelid together, as if from the same person. Per location only (Ghana children).

- **Data:** eyelids from Appiahene, Asare, Donkoh 2022 (Mendeley 10.17632/nt7r8hv2pz.1, CC BY 4.0, downloaded 2026-11-05): CP-AnemiC eyelid photos, pixel for pixel, but named like the nail and palm sets (Stage 13). **The link** is the label, batch and number in the file name (Anemic-105 / Anemic-FN-105 / AnemicP-105); the authors don't document it, so step 1 tests it.
- **Anemia:** Hb < 11.0 g/dL from the CP-AnemiC sheet (children 6-59 months), one label per child for all three body sites. The nail and palm file-name labels are not the target.
- **Inputs:** the 29 color numbers of each body site. *Early* = one model on the numbers of all the sites together; *late* = the mean of the single-site scores from the same model and folds. The rule ranks low redness (a*) and, for several sites, averages those ranks (no training).
- **Split:** 5-fold CV x 5 repeats by child, stratified on anemia; children that share any photo or near-copy stay in one fold. Also leaving one hospital out, for the children whose eyelid photo has no copy in CP-AnemiC (the only ones whose hospital we can trust). Bootstrap 95% CIs, 2000 resamples; AUROC and MAE changes are paired (same resampled children, same model).
- **Answers, fixed before running:** (a) the number links two sites if same-number photos agree in color more than in 0.01 of 2000 shuffles, both inside the whole batch and only among neighbouring numbers; (b) combining helps if eyelid + nail + palm beats the eyelid alone (CI above 0, same model); (c) pretend children = the same eyelids with a random nail and palm of the same label.
