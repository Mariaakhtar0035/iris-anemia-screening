# Stage 20: does adding age and sex help inside each location?

Generated by `python -m src.eyelid.metadata` at commit `7c9682a`; settings in `configs/metadata.yaml`. Mentor question (2026-11-03): DINOv2 turns the photo into a representation, so where does the metadata go? Until now nowhere: every model saw the eyelid only. Per location only (mentor advice 2026-11-03: don't aim for transfer between these small, very different datasets).

- **Photos:** Ghana, the 388 CP-AnemiC photos with no copy (children 6-59 months, **anemic = Hb < 11.0 g/dL** for both sexes); India (95) and Italy (122) from Eyes-Defy (adults, **WHO by sex: women < 12.0, men < 13.0 g/dL**; pregnancy not recorded). One photo per person. The cutoffs differ by dataset, but no model is carried between datasets.
- **Inputs:** `photo` = the 29 color numbers of the palpebral conjunctiva (or the DINOv2 embedding for the probe); `age + sex` = age (Ghana in months, Eyes-Defy in years) and sex (1 = male) alone; `photo + age + sex` = both side by side. The hospital is never an input.
- **Sex and the cutoff:** in India and Italy sex also sets the anemia cutoff, so part of any gain from sex there is the definition, not biology. Ghana has one cutoff for both sexes.
- **Split:** 5-fold CV x 5 repeats by photo, stratified by anemia; Ghana also leaving one hospital out (10 hospitals, pooled held-out scores). Bootstrap 95% CIs, 2000 resamples. The AUROC change is a paired bootstrap (same resampled photos), same model.
- **Italy early batch:** folders 1-31, where 21 of the 23 anemic patients are (Stage 10); scored from the same predictions.
- **Answer, fixed before running:** age and sex help in a location if, for the same model, photo + age + sex beats the photo alone (CI of the change above 0) and also beats age + sex alone.
