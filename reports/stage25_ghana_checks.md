# Stage 25: cheating and fairness checks on one Ghanaian child's eyelid, nail and palm

Generated by `python -m src.ghana_checks` at commit `1cf698e`; settings in `configs/ghana_checks.yaml`. The same children, folds and label as Stage 24 ([`stage24_ghana_link.md`](stage24_ghana_link.md)).

- **Children:** 302, each with an eyelid, nail and palm photo under the same file number. **Anemia: Hb < 11.0 g/dL** from the CP-AnemiC sheet (children 6-59 months), one label per child. Age and sex from the same sheet, when every copy of the photo agrees.
- **Scores:** held-out P(anemic) from 5-fold CV x 5 repeats by child (children sharing a photo in one fold), averaged over the repeats. *Late* = the mean of the three single-site scores. Bootstrap 95% CIs, 2000 resamples, paired where two scores are compared.
- **Answers, fixed before running:** (1) adding nail and palm is fair if it doesn't widen a gap (paired CI of the change in the gap's size not entirely above 0); (2) no shortcut if size and shape alone give an AUROC whose CI includes 0.5 or below 0.6; (3) same mistakes if the same-number score correlation's CI is above 0 and above random partners', and the child (not just the session) if same number minus neighbour is above 0; (4) what-if only.
